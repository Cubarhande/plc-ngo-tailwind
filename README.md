# PLC NGO – Full Stack MERN Project

A responsive NGO website built with **React.js, Tailwind CSS, Node.js, Express.js, and MongoDB**.

## Live Website

https://plc-ngo-tailwind.onrender.com/

## Tech Stack

* **Frontend:** React.js + Tailwind CSS
* **Backend:** Node.js + Express.js
* **Database:** MongoDB
* **Image Upload:** Multer
* **Email:**  Contact Form
* **Deployment:** Render

## Project Structure

```text
plc-ngo-tailwind/
├── client/    # Frontend
├── server/    # Backend
├── .gitignore
└── README.md
```

## Features

* Responsive NGO website
* Admin dashboard
* Admin authentication
* Dynamic content management
* Image upload
* Contact form
* Automatic email replies
